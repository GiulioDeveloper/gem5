# legacy-log: frozen pre-wiki notebooks

Everything here was written before the wiki existed (2026-06-27 to
2026-10-21) and is **frozen: do not edit these files**. They are a historic
record, not a strict source of truth. Claims may be stale, superseded or
inconsistent with each other. The wiki (`docs/wiki/`, start at
[[index]]) synthesizes what still holds and flags conflicts. Cite these
files from the wiki by vault path, e.g.
`[[legacy-log/research-log/agentic/2026-10-16-infinite-btb]]`.

## Paths inside these files are pre-move

The files were moved on 2026-10-21 and their contents were left untouched,
so the paths they mention are the old ones. Add the prefix to resolve them:
